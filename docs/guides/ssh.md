**Proyecto:** Blumelix / Blumix

## 1. Evidencia inicial

La revisión de contraseñas de Google Password Manager mostró:

- **792 sitios web y aplicaciones** comprobados.

- **889 contraseñas reutilizadas** — riesgo alto.
- **97 cuentas con una contraseña poco segura** — riesgo medio/alto.

> Nota: estos números pueden solaparse. No deben sumarse como si fueran cuentas independientes.

La evidencia visual corresponde a la captura de la revisión de contraseñas realizada el **14 de agosto de 2026**.

### Regla de privacidad

Blumelix **no debe almacenar contraseñas, códigos 2FA, cookies, tokens, claves de recuperación ni secretos**.

Para documentar el caso solo se registran metadatos, cantidades, acciones y resultados de verificación.

---

## 2. Objetivo

Reducir progresivamente la exposición de las cuentas mediante:

1. Cambiar primero las contraseñas vulneradas.
2. Eliminar la reutilización de contraseñas.
3. Sustituir las contraseñas débiles por credenciales únicas y robustas.
4. Activar y revisar la autenticación multifactor.
5. Revisar sesiones, dispositivos y accesos de terceros.
6. Verificar nuevamente Google Password Manager.
7. Registrar únicamente evidencia no sensible.

---

## 3. Orden recomendado de saneamiento

### Fase A — Prioridad crítica

Atender las **332 contraseñas vulneradas**.

Para cada cuenta:

- Cambiar la contraseña desde el sitio oficial.
- Crear una contraseña única.
- Cerrar sesiones antiguas cuando el servicio lo permita.
- Revisar actividad reciente o accesos sospechosos.
- Activar 2FA/MFA si está disponible.

**Importante:** si una contraseña vulnerada fue reutilizada en otros servicios, esos servicios también deben considerarse prioritarios.

### Fase B — Reutilización

Atender las **889 contraseñas reutilizadas**.

Objetivo:

> Una cuenta importante = una contraseña única.

### Fase C — Contraseñas débiles

Atender las **97 cuentas con contraseñas poco seguras**.

Priorizar:

1. correo principal;
2. cuentas financieras;
3. cuentas de recuperación;

#!/usr/bin/env python3

START = "<!-- BLUMIX_ROADMAP_START -->"
END = "<!-- BLUMIX_ROADMAP_END -->"


def backup_file(path: Path) -> Path:
    timestamp = datetime.now().strftime("%Y%m%d-%H%M%S")
    backup = path.with_name(
        f"{path.name}.backup-{timestamp}"
    )
    shutil.copy2(path, backup)
    return backup


def read_text(path: Path) -> str:
    return path.read_text(encoding="utf-8")


def write_text(path: Path, content: str) -> None:
    path.write_text(content, encoding="utf-8")


def build_block(roadmap: str) -> str:
    roadmap = roadmap.strip()

    return (
        f"{START}\n\n"
        "## 🗺️ ROADMAP\n\n"
        f"{roadmap}\n\n"
        f"{END}"
    )


def update_readme(readme: str, roadmap: str) -> str:
    block = build_block(roadmap)

    pattern = re.compile(
        re.escape(START) + r".*?" + re.escape(END),
        re.DOTALL,
    )

    if pattern.search(readme):
        return pattern.sub(block, readme, count=1)

    separator = "\n\n"

    if not readme.endswith("\n"):
        separator = "\n\n"

    return readme.rstrip() + separator + block + "\n"


def main() -> int:
    print()
    print("🚀 BLUMIX · ROADMAP → README")
    print("=" * 50)
    print()

    if not README.exists():
        print(f"❌ No existe: {README}")
        return 1

    if not ROADMAP.exists():
        print(f"❌ No existe: {ROADMAP}")
        return 1

    roadmap = read_text(ROADMAP).strip()

    if not roadmap:
        print("❌ ROADMAP.md está vacío.")
        return 1

    print(f"📄 README : {README}")
    print(f"🗺️  ROADMAP: {ROADMAP}")
    print()

    backup = backup_file(README)
    print(f"🛡️ Backup creado:")
    print(f"   {backup.name}")
    print()

    current_readme = read_text(README)
    new_readme = update_readme(current_readme, roadmap)

    write_text(README, new_readme)

    print("✅ README.md actualizado.")
    print()
    print("📌 El contenido de ROADMAP.md quedó integrado")
    print("   dentro de la sección:")
    print()
    print("   ## 🗺️ ROADMAP")
    print()
    print("🔐 El README anterior quedó respaldado.")
    print()

    blx_row "Kernel: $(uname -r)"
    blx_row "Uptime: $(uptime -p 2>/dev/null || uptime | sed 's/.*up //' | sed 's/,.*//')"
    blx_row "RAM: $(free -h | awk '/^Mem:/ {printf "%s / %s", $3, $2}')"

}

🔑 Conexión SSH
Blumix puede usarse en máquinas remotas vía SSH. Ideal para administrar servidores desde tu celular o laptop.
Configuración en el servidor

Conexión desde cliente
Método 1: SSH directo


ssh usuario@IP-EJEMPLO
# Una vez dentro:
blumix system
blumix network

Método 2: Configurar alias SSH
Editar ~/.ssh/config:

Host fedora HostName IP-EJEMPLO User usuario Port 22

Uso:

ssh fedora
blumix system

Método 3: Ejecutar comando remoto

ssh fedora "blumix system"
ssh fedora "blumix network"
ssh fedora "blumix security"

Ejemplo de uso real

# Conectar
ssh usuario@IP-EJEMPLO

# Ver estado del sistema
blumix system

# Ver red
blumix network

# Ver integraciones
blumix integrations

# Desconectar
exit

Firewall

Si el servidor tiene firewall activo:

# En el servidor (Fedora)
sudo firewall-cmd --add-service=ssh --permanent
sudo firewall-cmd --reload

Claves SSH (sin contraseña)

# En el cliente, generar clave
ssh-keygen -t ed25519 -C "blumix"

# Copiar clave pública al servidor
ssh-copy-id usuario@IP-EJEMPLO

# Ahora conecta sin contraseña
ssh usuario@IP-EJEMPLO

Blumix en múltiples máquinas

# Instalar Blumix en cada máquina
# Configurar SSH config con múltiples hosts

Host fedora
    HostName IP-EJEMPLO
    User usuario

Host termux
    HostName IP-EJEMPLO-2
    User usuario_termux
    Port 8022

# Uso
ssh fedora "blumix system"
ssh termux "blumix network"

EOF
